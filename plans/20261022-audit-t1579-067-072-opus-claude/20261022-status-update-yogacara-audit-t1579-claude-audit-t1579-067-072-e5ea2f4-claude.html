6. 技術細節附錄

Root cause / evidence

job 666c：validator_error 依序是 finding requires source and translation evidence（evidence 物件少了 reference_ids）和 Expecting ',' delimiter: line 1 column 745（finding 的 required_change 後面多了一個 }）。prompt 裡的 schema 有把 reference_ids 列為必填，所以 validator 比 schema 嚴這個假設排除，根因是模型沒有被強制遵守 schema。

claude -p --json-schema 會把 schema 包成 tool 的 input schema，API 回 400 input_schema does not support oneOf, allOf, or anyOf at the top level。最上層的 oneOf 只負責把 verdict 綁到 findings，validate_review_contract 會再檢查一次，所以拿掉它不會讓契約變鬆。fix 的 schema（有 lookahead regex）也實測被 API 接受。

job 8998 耗時：fix 平均 168 秒（thinking 10.2k token），review high 50–57 秒，doctrine xhigh 123 秒。list price：fix US$3.70、review_terms US$3.11、doctrine US$3.82。
